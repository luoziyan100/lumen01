## 1. MODIFY `src/agent/tools.ts`

### 1.1 DELETE 泛化的“个/条/项”结果集锚点

当前问题：

- `hasStrongResultSetAnchor()` 接受 `第 N 个/条/项`。
- `inferResultIndicesFromText()` 接受 `第 N 个/条/项`。
- `inferLeadingCount()` 接受 `前 N 个/条`。

这会导致：

```text
前 5 个有什么区别？
第 2 个是什么意思？
```

被错误绑定到 R1 论文结果集。

### 1.2 MODIFY `hasStrongResultSetAnchor(userText)`

把它改成只允许下面这些强锚点。

允许：

```text
R1
R1-1
R1 前 5 篇
R1-1 到 R1-5
第 1 篇
第 1-5 篇
第 1 篇论文
第 1 条结果
前 5 篇
前 5 篇论文
前 5 条结果
刚才那 10 篇论文
刚才那 10 篇文献
你刚才筛出来的论文
你刚才列出的结果
```

禁止：

```text
第 1 个
第 2 项
第 3 条
前 5 个
前 5 项
前 5 条
那几个
这几个
这些
它们
```

注意：`第 1 条结果` 可以，`第 1 条` 不可以。`前 5 条结果` 可以，`前 5 条` 不可以。

### 1.3 MODIFY `inferResultIndicesFromText(userText)`

它只能解析这些形式：

```text
第 N 篇
第 N 篇论文
第 N 条结果
第 N 个结果
第 N 项结果
第 N 到 M 篇
```

它不能解析：

```text
第 N 个
第 N 条
第 N 项
```

### 1.4 MODIFY `inferLeadingCount(userText)`

它只能解析这些形式：

```text
前 N 篇
前 N 篇论文
前 N 条结果
前 N 个结果
前 N 项结果
```

它不能解析：

```text
前 N 个
前 N 条
前 N 项
```

### 1.5 MODIFY `resolveResultSetReference()`

先判断 `hasStrongResultSetAnchor(userText)`。

如果为 false，直接返回：

```ts
{ ok: false, error: '用户没有明确引用已有搜索结果集。' }
```

不要让 `explicitIndices.length > 0` 或 `leadingCount` 单独绕过强锚点判断。

推荐结构：

```ts
const strongAnchor = hasStrongResultSetAnchor(userText)
if (!strongAnchor) {
  return { ok: false, error: '用户没有明确引用已有搜索结果集。' }
}

const explicitIndices = inferResultIndicesFromText(userText)
const leadingCount = inferLeadingCount(userText)
...
```

### 1.6 MODIFY `resolvePaperReferences()`

删除这些 fallback：

```ts
if (/这篇|这个论文|这几篇|这些|它们|他们|那几篇|刚才/.test(userText) && context.currentPaper) { ... }
if (lastSearchResults.length > 0) return { ok: true, data: lastSearchResults.slice(0, fallbackLimit) }
if (context.currentPaper) return { ok: true, data: [context.currentPaper] }
```

替换为更严格规则：

只有满足以下任一条件，才可以从 `lastSearchResults` 或 `currentPaper` 选论文：

- `hasStrongResultSetAnchor(userText) === true`
- `plan.paperReference` 存在
- 用户文本明确包含论文集合语义，例如：

```text
这些论文
这些文献
这几篇论文
刚才那几篇论文
the papers
these papers
```

禁止：

```text
这些分类综合对比一下
这些方法有什么区别
它们之间是什么关系
```

绑定旧论文。

## 2. MODIFY `src/agent/reference-resolver.ts`

### 2.1 DELETE `Boolean(input.context.currentPaper)` 作为充分条件

当前代码类似：

```ts
const shouldResolveAsPaper = Boolean(input.context.currentPaper)
  || hasExplicitPaperSemantics(input.userText)
  || hasStrongResultSetAnchor(input.userText)
```

必须删除 `Boolean(input.context.currentPaper)` 这一项。

原因：

`currentPaper` 是持久状态，不代表用户本轮仍在说这篇论文。

### 2.2 ADD helper: `hasExplicitCurrentPaperAnchor(text)`

新增 helper，建议放在 `reference-resolver.ts`。

它只在这些文本上返回 true：

```text
这篇论文
这篇 paper
该论文
当前论文
这篇文献
刚才那篇论文
这篇文章
```

它不能因为裸词返回 true：

```text
它
这个
这个东西
这件事
```

### 2.3 ADD helper: `recentTurnIsPaperFocused(input)`

新增 helper，检查最近 2 条消息。

返回 true 的条件：

- 最近 2 条消息包含 `currentPaper.title` 的一部分，或
- 最近 2 条消息包含明确论文语义：

```text
论文 / 文献 / paper / DOI / arXiv / PDF / 摘要 / 方法 / 实验 / 结论 / 证据来源
```

返回 false 的例子：

```text
机器学习有哪些分类？
agent 和 workflow 有什么区别？
这些分类有什么区别？
```

### 2.4 MODIFY paper pronoun binding

改成下面的规则：

```ts
const explicitCurrentPaperAnchor = hasExplicitCurrentPaperAnchor(input.userText)
const barePronoun = /它|这个|那篇/.test(input.userText)
const recentPaperFocused = recentTurnIsPaperFocused(input)
const strongResultSetAnchor = hasStrongResultSetAnchor(input.userText)
const explicitPaperSemantics = hasExplicitPaperSemantics(input.userText)

const shouldResolveAsPaper =
  strongResultSetAnchor
  || explicitCurrentPaperAnchor
  || (barePronoun && explicitPaperSemantics && recentPaperFocused)
```

解释：

- `这篇论文的结论是什么？` 可以绑定 currentPaper。
- `它的结论是什么？` 只有最近还在谈论文时才可以绑定 currentPaper。
- `它和 workflow 有什么区别？` 即使 currentPaper 存在，也不能绑定 currentPaper。

### 2.5 MODIFY ambiguity

只有用户明确问论文，但没有唯一论文对象时，才返回 ambiguity。

允许 ambiguity：

```text
这篇论文的结论是什么？
该论文的方法是什么？
```

禁止 ambiguity：

```text
它和 workflow 有什么区别？
这个设计为什么不行？
```

这些应该放行给 planner。

## 3. MODIFY `src/agent/context-pack.ts`

### 3.1 ADD helper: `shouldRenderRecentResultSets(pack)`

新增 helper：

```ts
function shouldRenderRecentResultSets(pack: AgentContextPack): boolean {
  return Boolean(pack.activeObjects.referencedPapers?.length)
    || pack.decision.target === 'resolved_result_set_items'
    || pack.decision.intent === 'paper_detail'
    || pack.decision.intent === 'paper_preview'
    || pack.decision.intent === 'deep_research'
}
```
