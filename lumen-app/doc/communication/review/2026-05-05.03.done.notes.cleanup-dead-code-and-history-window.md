## Review 关注点

- `trimHistory()` 当前不做 LLM 摘要，只做确定性截断，符合 brief 的 Phase 2 范围。
- 如果 system/tool_result 数量本身超过 `maxMessages`，函数会保留它们，因此返回长度可能超过 `maxMessages`；这是为了满足“保留 tool_result、永不删除 system”的约束。
