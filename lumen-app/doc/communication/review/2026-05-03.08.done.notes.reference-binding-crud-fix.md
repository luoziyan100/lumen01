## Summary

已按 `.08` 的 CRUD 指令修复 reference binding 和 ContextPack 裁剪问题。本次只修改现有函数，没有新增新的 resolver/router 架构层。

## tools.ts

删除/修改的 regex 行为：

- `inferResultIndicesFromText()` 不再解析 `第 N 个`、`第 N 条`、`第 N 项`。
- `inferResultIndicesFromText()` 现在只解析：
  - `第 N 篇`
  - `第 N 篇论文/文献`
  - `第 N 条结果`
  - `第 N 个结果`
  - `第 N 项结果`
  - `第 N 到 M 篇`
- `inferLeadingCount()` 不再解析 `前 N 个`、`前 N 条`、`前 N 项`。
- `inferLeadingCount()` 现在只解析：
  - `前 N 篇`
  - `前 N 篇论文/文献`
  - `前 N 条结果`
  - `前 N 个结果`
  - `前 N 项结果`
- `hasStrongResultSetAnchor()` 不再把泛化 `个/条/项` 当结果集锚点。
- `resolveResultSetReference()` 现在先检查 `hasStrongResultSetAnchor()`；false 时直接返回“用户没有明确引用已有搜索结果集”。
- `resolvePaperReferences()` 删除了这些隐式 fallback：
  - 裸 `这些/它们/他们/刚才` + `currentPaper`
  - 无锚点时直接取 `lastSearchResults`
  - 无锚点时直接取 `currentPaper`

## reference-resolver.ts

删除的错误条件：

- 删除 `Boolean(input.context.currentPaper)` 作为绑定论文的充分条件。

新增 helper：

- `hasExplicitCurrentPaperAnchor(text)`
  - 只允许 `这篇论文`、`这篇 paper`、`该论文`、`当前论文`、`这篇文献`、`刚才那篇论文`、`这篇文章`。
  - 不允许裸 `它`、`这个`、`这个东西`、`这件事`。

- `recentTurnIsPaperFocused(input)`
  - 只看最近 2 条消息。
  - 如果包含 currentPaper title 片段，或明确论文语义：`论文/文献/paper/DOI/arXiv/PDF/摘要/方法/实验/结论/证据来源`，才返回 true。

paper pronoun 绑定规则改为：

```ts
strongResultSetAnchor
|| explicitCurrentPaperAnchor
|| (barePronoun && explicitPaperSemantics && recentPaperFocused)
```

所以 `它和 workflow 有什么区别？` 即使存在 stale `currentPaper`，也不会绑定论文。

## context-pack.ts

新增：

- `shouldRenderRecentResultSets(pack)`

裁剪规则：

- 只有以下情况渲染 recent result sets：
  - 有 `referencedPapers`
  - `decision.target === "resolved_result_set_items"`
  - intent 是 `paper_detail` / `paper_preview` / `deep_research`
- 普通 direct answer 不渲染 R1/R2 列表，显示：

```text
无。本轮没有引用历史搜索结果。
```

## runtime.ts

direct answer 分支仍保留 ContextPack，但依赖 `context-pack.ts` 的裁剪逻辑。

也就是说：

- 普通 answer 可以带本轮 resolved question / constraints。
- 不会在普通 answer 中注入 recent R1/R2 论文列表。

## Required Test Matrix

代码级验证结果：

### 不能绑定旧论文

- `机器学习有哪些分类？`
  - 无强锚点，不会进入 `resolveResultSetReference()`。
- `前 5 个有什么区别？`
  - `前 N 个` 不再是 result set anchor。
- `第 2 个是什么意思？`
  - `第 N 个` 不再是 result set anchor。
- `这些分类综合对比一下`
  - 弱指代，不绑定 R1。
- `它们之间是什么关系？`
  - 弱指代，不绑定 R1。
- `agent 和 workflow 有什么区别？`
  - 无论文锚点，不绑定 currentPaper。
- `它和 workflow 有什么区别？`
  - 裸 `它` + 非论文语义，不绑定 currentPaper。

### 必须绑定旧论文

- `R1 前 5 篇做报告`
  - `R1` + `前 N 篇` 是强锚点。
- `R1-1 到 R1-5 的链接`
  - `R1-1` 是强锚点，链接请求可 deterministic answer。
- `第 1 篇论文的结论是什么？`
  - `第 N 篇论文` 是强锚点。
- `前 5 篇论文综合对比`
  - `前 N 篇论文` 是强锚点。
- `刚才那 10 篇论文的前 5 篇做报告`
  - `刚才那 N 篇论文` 是强锚点。

### currentPaper 不能 stale 劫持

- `agent 和 workflow 有什么区别？`
  - 不绑定 currentPaper。
- `它和 workflow 有什么区别？`
  - 不绑定 currentPaper。
- `这篇论文的结论是什么？`
  - 有 explicit current paper anchor，可绑定 currentPaper。

### ContextPack 裁剪

- `机器学习有哪些分类？`
  - direct answer 的 ContextPack 不渲染 R1/R2 result set 列表。
- `R1 前 3 篇做报告`
  - 有 referenced papers，ContextPack 渲染 recent result sets 和 referenced papers。
