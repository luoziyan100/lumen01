## Adapter behavior

### Claude

Input:

```json
[
  {"role":"user","content":"Search LLM papers."},
  {"role":"assistant","content":"","toolCalls":[{"id":"toolu_1","name":"academic_search","arguments":{"queries":["LLM"]}}]},
  {"role":"tool_result","toolCallId":"toolu_1","content":"{\"results\":[{\"title\":\"Paper A\"}]}"}
]
```

Request messages:

```json
[
  {"role":"user","content":"Search LLM papers."},
  {"role":"assistant","content":[{"type":"tool_use","id":"toolu_1","name":"academic_search","input":{"queries":["LLM"]}}]},
  {"role":"user","content":[{"type":"tool_result","tool_use_id":"toolu_1","content":"{\"results\":[{\"title\":\"Paper A\"}]}"}]}
]
```

Claude response parsing separates `text` blocks from `tool_use` blocks and returns `ToolCall[]` with object arguments from `input`.

### OpenAI

Input:

```json
[
  {"role":"assistant","content":"","toolCalls":[{"id":"call_1","name":"academic_search","arguments":{"queries":["LLM"]}}]},
  {"role":"tool_result","toolCallId":"call_1","content":"{\"ok\":true}"}
]
```

Request messages:

```json
[
  {"role":"assistant","content":null,"tool_calls":[{"id":"call_1","type":"function","function":{"name":"academic_search","arguments":"{\"queries\":[\"LLM\"]}"}}]},
  {"role":"tool","tool_call_id":"call_1","content":"{\"ok\":true}"}
]
```

OpenAI response parsing reads `message.tool_calls`, requires `type: "function"`, and `JSON.parse`s function `arguments`.

### ReAct fallback

System prompt injection:

```text
<tool_call>
{"name": "工具名", "arguments": {...}}
</tool_call>
```

For DeepSeek/custom and `openai-codex` fallback, tool results are represented as ordinary user observations:

```text
Observation for react_1:
{"ok":true}
```

Responses with valid `<tool_call>{...}</tool_call>` blocks produce one `ToolCall`. Plain text and malformed tool blocks fall back to normal assistant text.
