## Summary

Implemented the P0/P1/P2 brief:

- Added persistent `research_artifacts` storage for structured research context.
- Restored latest `search_results` and `current_paper` artifacts when loading a research project.
- Saved `search_results` after successful external search.
- Saved `current_paper` after `paper_detail` and `paper_preview`.

- Tightened PDF validation to require `%PDF` in the first 1024 bytes.
- Replaced fixed “正在规划回答...” with looping `Thinking`, `Thinking.`, `Thinking..`, `Thinking...`.

## Notes For Review

- `research_artifacts` is intentionally separate from `research_notes` so later artifact types such as `paper_preview`, `deep_research_report`, and `import_candidate` can be added without bloating note rows.
- `current_paper` does not import or persist a PDF into the library. It only records the structured search result plus evidence level.
- Search results from older localStorage/dev sessions may not have the new PDF fields; preview uses nullish fallback and still behaves safely.
- The migration runner still uses the existing non-transactional migration style. This PR adds v6 using the current pattern but does not refactor the migration framework.
