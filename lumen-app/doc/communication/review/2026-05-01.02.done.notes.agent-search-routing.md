## 实现摘要

- `ResearchPage.tsx` 已移除首轮强制读取 PDF 的 workflow。页面只负责传入用户输入、会话历史、当前日期/时区、论文库状态和 `loadLocalPaperContext`，是否读本地论文由 agent planner 决定。
- Agent planner schema 已扩展 `localPaperRequest`、`recencyIntent`、`timeRange`、`sortMode`。同时注入 `currentDate`、`timezone`、论文库状态和工具成本说明。
- 简单确定性问题增加 fast path：例如当前年份、当前日期直接回答，不读 PDF，不搜索。
- DeepSeek agent role routing 已接入：
  - planner / reflector / simple_answer / risk_sensor -> `deepseek-v4-flash`
  - synthesizer / local_paper_analysis -> `deepseek-v4-pro`
  - 非 DeepSeek provider 保持原 default model 行为。
- `searchPapers(query, limit, options, signal)` 已支持 `fromDate`、`untilDate`、`sortMode`，并把参数传给 Tauri 与 Vite dev fallback。
- Rust Tauri 搜索与 Vite dev fallback 均已支持结构化时效搜索：
  - OpenAlex: `from_publication_date` / `to_publication_date`，newest 时按 publication date 排序。
  - Semantic Scholar: `/paper/search/bulk`，`publicationDateOrYear`，newest 时 `publicationDate:desc`。
  - Crossref: `from-pub-date` / `until-pub-date`，newest 时 `sort=published&order=desc`。
  - arXiv: newest 时 `sortBy=submittedDate&sortOrder=descending`，并做本地日期过滤。
- 搜索结果新增 `published_date`，格式化输出会优先展示精确发布日期。
- 搜索结果最终排序已区分 `newest`：日期优先，质量分作为次级排序。
- abort trace 已修正为大小写不敏感识别 abort，工具层取消时抛 `AbortError`，避免用户停止被记成 failed。

## 未完全验证 / 风险

- 没有跑完整 live 外部学术搜索端到端验收，避免把 OpenAlex / Semantic Scholar / Crossref / arXiv 的网络抖动混入本轮代码验证。
- DeepSeek `deepseek-v4-flash` / `deepseek-v4-pro` 的真实线上 JSON mode 兼容性需要在用户配置的 API key 下实测。如果 DeepSeek 对 `response_format` 支持有差异，建议只对 planner/reflector 保留 JSON prompt，临时移除 API 层 `response_format`。
- Semantic Scholar bulk endpoint 在无 API key 下可能有更严格 rate limit；当前代码会把单源失败降级为其它源结果。
