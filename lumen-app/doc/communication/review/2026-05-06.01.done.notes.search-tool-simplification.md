## 完成内容

- `academic_search` 工具 schema 从多参数改为单参数 `query`，删除 `queries`、`time_range`、`sort`、`mode`、`arxiv_categories`、`limit`。
- `executeAcademicSearch()` 改为单 query 执行，固定 `limit = 20` 和 `{ sortMode: 'newest' }`。
- `mergeSearchBatches()` 合并去重后优先按 `published_date` 降序排序，日期相同再按 `quality_score`。
- 搜索结果新增返回 `published_date` 和 `journal`，摘要片段从 800 提升到 1200 字符。
- system prompt 更新为让模型把日期约束直接写进英文 query，并由模型判断结果重要性。
- adapter message-format 测试中的示例工具参数同步为 `query`。
- 可选 Rust 优化已完成：`citation_score` 权重从 `ln(count) * 8` 降到 `* 2`，`tier_score` 从 `55/35/20` 降到 `8/5/3`。
