# Lumen Desktop UI Kit

桌面应用的高保真 UI 套件。核心屏幕为点击式原型。

## 结构

- `index.html` — 入口，路由到各屏幕
- `AppShell.jsx` — 窗口外壳（titlebar + sidebar + main）
- `Library.jsx` — 文献库列表
- `Reader.jsx` — PDF 阅读器 + AI 侧栏
- `DeepResearch.jsx` — 深度研究对话
- `Graph.jsx` — 引文图谱
- `components.jsx` — 共享小组件（Button, Tag, Icon, PaperCard...）

## 尺寸

设计宽度 **1440 × 900**。窗口最小 1120。左 sidebar 240px。
